# Vision — BAI Digital

**BAI Digital** (www.baidigital.xyz) is an AI company built as: **Hugo as CEO,
at most 1–4 more humans, and a fleet of AI agents as the workforce.** The
company is the proof of its own thesis — an organisation that runs on
automation, where agents build well-described features in vertical slices and
the humans direct, review, and decide.

## The three legs

1. **AI agency / studio** — BAI Digital automates everything about its own
   operations: development, outreach, reporting. Agents push code as
   `feat/<slug>` pull requests; Hugo approves; merged PRs deploy.
2. **Investment company** — several projects run in parallel; the investment
   leg tracks and analyses positions (crypto/market intelligence via MCP
   providers like LunarCrush and Quartr).
3. **Product studio** — multiple webapp business ideas, each its own repo
   born from `template-webapp`. The first product is **automazing**
   (automazing.life): automates everything in a person's life, privately and
   at work/in the companies they own. Sold as SaaS, B2B and B2C subscription.

## Operating principles

- **Agents build, humans approve.** Nothing reaches `main` without a human-
  reviewed PR. The review surface is GitHub, never raw diffs or patch files.
- **Small repos, sharp context.** One repo per product; agents perform best
  when the repo fits their head. Shared code is extracted only on the third
  duplication, never preemptively.
- **Vertical slices.** A feature owns its whole slice — UI, API, data — and
  is described well enough that an agent can build it end-to-end.
- **Everything graded.** Agent work is judged against explicit definitions of
  done (outcome rubrics, verify suites), not vibes.
- **Context is infrastructure.** ai/-folders and this repo are maintained
  like code, because they are what the workforce runs on.
