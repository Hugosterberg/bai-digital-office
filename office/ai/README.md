# ai/ — product context for AI agents

Fill these in when the product is born (they are part of the template so no
project starts context-less). Company context lives in
[bai-digital-office/ai](https://github.com/bai-digital-office/ai) — read that first.

| File | What it holds |
|---|---|
| VISION.md | What this product is, for whom, and why it wins |
| ARCHITECTURE.md | Stack, data model, invariants (tenancy, auth), integrations |
| ROADMAP.md | Versioned plan: shipped / v1 / v2 / parked |
| DECISIONS.md | Product-level ADRs |

Keeping these true is part of every feature's definition of done.
